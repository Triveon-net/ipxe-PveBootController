Client agent (goes into the node image)

iPXE only loads your kernel — the agent runs inside the image. It finds its own MAC (the NIC that reaches the controller), then opens a persistent WebSocket (ws://<controller-host>{{ config.ws_path }}) and waits for the controller to push its configuration — no polling. Pick either variant:

One-line install (on the node)

Installs pve-agent.py, the systemd unit and /etc/pve-agent.conf (pointed at this controller), then enables the service but leaves it stopped.

curl -fsSL {{ base_url() }}/agent/install.sh | sh
pve-agent.py recommended

Python (standard library only). Reports the hardware and applies hostname, management network, Corosync/cluster and NFS storages. Drop it in the image as /usr/local/bin/pve-agent.py and enable the unit so it runs on first boot. Supports --dry-run and --root.

python3 /usr/local/bin/pve-agent.py Download pve-agent.py Download pve-agent.service Download pve-agent.conf
pve-report.sh

Minimal POSIX shell — reports the hardware and saves the returned config to /run/pve-config.json (applies nothing itself).

curl -fsSL {{ base_url() }}/agent/pve-report.sh | sh Download pve-report.sh
